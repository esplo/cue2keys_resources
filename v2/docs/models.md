# 3Dモデル

このページでは、各モジュールの3Dモデルへのリンクをまとめています。
3Dプリンターをお持ちであれば、色変更や交換・カスタマイズなどにご利用ください。

なお、全てネジ不要のはめ込み式なので、フィラメント以外の部品は必要ありません。

## 印刷のTips

- 土台と接触する凹凸部分は、0.12mm以下のLayer heightで印刷してください。Layer Height Modifierを使うと、対象部分だけ個別にLayer heightを設定できます。
